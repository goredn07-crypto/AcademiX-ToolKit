
# AcademiX Toolkit: Multi-Purpose Student & Engineering CLI Suite

AcademiX Toolkit is a Python-based command-line application that brings together useful tools for students, especially engineering students. It helps with everyday academic tasks, mathematical calculations, engineering conversions, and basic system diagnostics, all from a single terminal.

The entire project is built using Python's standard libraries, so there's no need to install any additional packages.

---

## Why I Built This

As an engineering student, I often find myself switching between different websites, calculators, and spreadsheets for simple tasks. Whether it's checking how many classes I can miss without falling below the attendance requirement, calculating my SGPA, or converting numbers between different bases, I wanted a way to do everything in one place.

That's how the idea for AcademiX Toolkit came about.

Instead of relying on multiple tools, I decided to build a single Python application that could handle:

- **Attendance Tracking:** Calculate attendance percentages and find out how many classes I can safely miss while maintaining the required attendance.
- **Grade & SGPA Calculator:** Estimate semester grades and SGPA using CAT and FAT marks, subject credits, and grading systems.
- **Engineering Utilities:** Perform number-system conversions, scientific calculations, and other commonly used engineering calculations.
- **System Diagnostics:** Check basic hardware information and system performance directly from the terminal.

One of my main goals was to keep the project simple, lightweight, and easy to use. I built it entirely with Python's standard libraries, without depending on any third-party packages.

Apart from being useful for everyday college work, this project also gave me a chance to improve my Python skills, work with different modules, and implement calculations and algorithms from scratch.
